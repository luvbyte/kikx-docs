# Installation & Setup

To get started with the KIKX server environment, ensure your system meets the prerequisites and follow the setup instructions below.

## 📋 Prerequisites

* **Python 3.8+** installed on your system.
* **Make** build tool.
* **Git** for cloning the repository.

---

## ⚙️ Setup & Running Instructions

Open your terminal and run the following commands:

```bash
# Clone the repository
git clone https://github.com/luvbyte/kikx.git

# Navigate into the project directory
cd kikx

# Run setup (creates virtual environment and file system)
make setup

# Start the server
make run

```
