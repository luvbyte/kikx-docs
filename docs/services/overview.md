# KIKX Services Overview

The KIKX architecture provides a robust suite of client-side service modules that bridge application frontends with KIKX backend.

## 🛠️ Services

* **[FS](fs.md):** File System service.
* **[KV](kv.md):** Key-Value service.
* **[ProxyService](proxy.md):** Non-CORS blocking network request proxy.
* **[OSService](os.md):** Useful Operating-System functions.
* **[Tasker](tasker.md):** App running process management.
* **[Micro](micro.md):** App Long-running process management.

* **[System](system.md):** Kikx system service for kpm, alerts, invoker, ...
* **[Alerts](alerts.md):** Notification and custom alert builder UI.
* **[Kpm](kpm.md):** Package manager and installer pipeline for local, storage, and GitHub apps.
* **[Invoker](invoker.md):** System action dispatcher for opening apps and modifying UI settings.
